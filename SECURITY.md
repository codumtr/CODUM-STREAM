## Güvenlik İlkeleri (Security by Design)

1. **Yayıncı Güvenliği (Streamer Privacy Shield):**
   * Canlı yayında ekran paylaşırken yayın anahtarının (Stream Key) ve API anahtarlarının kazara sızmaması için stüdyo panelinde `🛡️ Yayıncı Koruması` özelliği varsayılan olarak aktiftir.
2. **Kişisel Veri:**
   * Kod tabanında hiçbir sabit API anahtarı, kullanıcı şifresi veya telemetri izleyici bulunmaz.
3. **Güvenlik Açığı Bildirimi:**
   * Herhangi bir güvenlik açığı veya yetkilendirme zaafı tespit ederseniz, lütfen herkese açık Issue açmak yerine özel olarak repo yöneticisiyle iletişime geçiniz.
